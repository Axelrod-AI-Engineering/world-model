# Railway infrastructure

`railway.ts` declares this repository's part of the shared Axelrod Railway project: the `world-model` and `world-model-ingestion` services and the world model's volume in `dev`, and the `world-model-data` service and its volume in `production`, through the named IaC partial `world-model`.

The release runbook, the verification steps, Basic Auth, and the shared-project caveats are in [docs/deployment.md](../docs/deployment.md).
