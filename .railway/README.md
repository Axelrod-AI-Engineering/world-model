# Railway infrastructure

`railway.ts` declares this repository's part of the shared Axelrod Railway project: the `world-model`, `world-model-ingestion` and `world-model-data` services and their volumes, all in `dev`, through the named IaC partial `world-model`.

The release runbook, the verification steps, Basic Auth, and the shared-project caveats are in [docs/deployment.md](../docs/deployment.md).
